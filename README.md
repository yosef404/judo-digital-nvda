# ג'ודו דיגיטלי ל-NVDA

משחק ג'ודו בעברית לעיוורים ולקויי ראייה, כתוסף ל-NVDA. כולל שיעורי ג'ודו וערכים עם שאלות, תרגילי קצב ותגובה, משחקי ידע וקרבות מול המחשב או מול שחקן נוסף באותה מקלדת.

## דרישות

- Windows עם NVDA 2026.1 ומעלה, המבוסס על Python 3.13 בגרסת 64 סיביות.
- רמקולים או אוזניות לשימוש במצב השמע או במצב המשולב.

## התקנה ופתיחה

1. הורידו את קובץ התוסף המצורף לגרסה באזור Releases.
2. פתחו את הקובץ ואשרו את ההתקנה ב-NVDA. הפעילו מחדש את NVDA לפי ההנחיה.
3. פתחו את המשחק מתפריט כלים של NVDA או באמצעות NVDA+Shift+J.

## תחילת משחק

- במסך הפתיחה לחצו Enter או רווח.
- בחרו שחקן 1 או 2, ואז יריב: מחשב או אדם נוסף.
- השתמשו בספרות בהתאם להוראות הנשמעות. רווח חוזר על הוראות התפריט; 0 או Escape חוזרים.
- בתפריט הראשי, 7 פותח את המדריכים ו-6 פותח את הכרת המקשים.
- בשיעורי הלימוד והערכים יש אותן שאלות בשני מצבי היריב. במצב שמע השאלה מתחילה אוטומטית בסיום השיעור. במצב תמונה או משולב, Enter ממשיך לשאלה.

אפשר לבחור מצב שמע, מצב תמונה או מצב משולב, וכן גופן מוגדל וניגודיות גבוהה.

## גרסה 1.0

גרסה 1.0 כוללת את תיקוני קליטת Enter והשמע מגרסת הבדיקה, את שתי אפשרויות התשובה בשאלה 5 בשיעורי הערכים, ומעבר אוטומטי לשאלה בסיום שיעור במצב שמע. במצב תמונה או משולב נשמרו הדפדוף ו-Enter להמשך.

## דיווח על תקלה

ציינו את גרסת NVDA, גרסת התוסף, המסך שבו אירעה התקלה והמקשים שנלחצו. במקרה של שגיאת שמע, ציינו גם את שעת התקלה כדי שיהיה קל למצוא אותה ביומן NVDA.
